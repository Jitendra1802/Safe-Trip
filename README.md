# 🌍 Safe Trip

**Safe Trip** is a travel web application which provides users an easy and user friendly way of exploring travel destinations and travel packages.

## ✨ Features

* 🏠 Browse travel destinations
* 🔍 Search travel packages
* 💰 Filter prices
* 🏷️ Filter by category
* ↕️ Sort packages
* 📋 Details of travel packages
* 📅 Travel booking page
* 📞 Contact, FAQ & Testimonials pages

## 🛠️ Technologies Used

**Frontend:** HTML, CSS, JavaScript

**Backend:** Node.js, Express.js *(In Progress)*

**Database:** MongoDB Atlas *(In Progress)*

## 🚧 Project Status

The frontend of this application is complete and I am currently working on adding a **Node.js + Express.js backend with MongoDB Atlas integration** to make this application completely dynamic.
